# Diwali Sales Analysis | Excel & Power BI
**Project Overview**

This mini project focuses on analyzing Diwali sales data to understand customer behavior, product performance, and revenue trends using Microsoft Excel and Power BI. The project aims to support better business decision-making during festive sales seasons.

**Objectives**

Study overall sales trends during the Diwali season

Identify top-performing products and categories

Analyze customer demographics and purchasing patterns

Present insights through interactive dashboards

**Tools Used**

Microsoft Excel – Data cleaning and analysis

Power BI – Data visualization and dashboard creation

**Dataset Description**

The dataset contains customer information such as age, gender, marital status, location, product categories, order quantities, and sales amount.

**Key Insights**

Married women aged 26–35 made the highest purchases

Clothing and electronics were the top-selling categories

Urban regions generated the most revenue

Festival discounts significantly increased sales volume

**Project Contents**

Raw and cleaned Excel datasets

Power BI interactive dashboard

Project documentation

**Dashboard Highlights**

Sales by age group, gender, and marital status

Top product categories and regions

Revenue trends and customer segmentation

 **Conclusion**

This analysis helps businesses improve festive marketing strategies, optimize inventory, and increase customer satisfaction using data-driven insights.
